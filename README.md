# Quiver

Semantic discovery and execution layer for AI capabilities. Any LLM finds and runs the right tool or model at runtime — no static wiring, no vendor lock-in.

```
quiver.query("transcribe this audio")   → finds the right specialist
quiver.execute(data, capability_id)     → runs it, returns structured output
```

Works with Claude, GPT-4o, Gemini, LangChain, or any HTTP client. Your keys, your tools, any LLM.
